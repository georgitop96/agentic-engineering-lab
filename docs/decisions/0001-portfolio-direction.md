# 0001: Product-first public portfolio

## Status

Accepted.

## Decision

The former learning repository remains a private local archive. This fresh
repository contains only public-facing, complete applications and their
supporting documentation.

## Rationale

Separating histories keeps educational experiments recoverable without making
the public portfolio look like a collection of unfinished tutorials. It also
allows the first application to establish its own quality bar and release
history.

## Consequences

The archive is not available from this repository. Public documentation must
describe only implemented behavior, and future applications should have
independent project boundaries.
